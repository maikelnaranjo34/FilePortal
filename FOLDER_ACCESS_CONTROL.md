# Folder access control

An administrator can browse and manage files inside the configured roots. To give a regular account access, open **Manage Users**, select **Folders** beside the user, choose folders from the configured roots, and save.

The user can list and work with files within the assigned folders and their descendants. An empty assignment grants no file access. Folder changes take effect on subsequent requests. The folder picker only displays folders and is available to administrators.

Portal application files, the user data directory, and filesystem links are excluded from browsing. If a root or an assignment becomes unavailable under the hosting identity, it will disappear from the user's root list until access is restored.
